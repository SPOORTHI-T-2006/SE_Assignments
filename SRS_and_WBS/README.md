# 4-SRS_and_WBS

This folder has the Software Requirements Specification and the Work Breakdown Structure for the project.

Files:
- SRS.pdf : the Software Requirements Specification. It covers the introduction, overall description, system features (functional requirements), non-functional requirements, external interface requirements, constraints and acceptance criteria.
- WBS.pdf : the Work Breakdown Structure. It breaks the project into work packages: project management, requirements engineering, design, development, testing, documentation, and deployment and review.

Note:
The requirements used in the SRS are the same ones given in the 1-RE folder.
