# Micro-Lending & Peer Credit Risk Assessor

This folder contains all the documents for my individual project assignment.

About the project:
The system is a micro-lending platform where a borrower submits financial details and the system works out a credit risk rating (Low, Medium or High) using debt-to-income ratio, repayment history and employment stability. Peer lenders can see this rating before lending. If a borrower is High risk, a warning is triggered. Once a loan is approved, a repayment schedule is generated. Repayments and EMI distribution run inside database ACID transactions, and borrower financial data is protected from unauthorized access.

Folder structure:

Requirements Engineering documents.
- FR_and_NFR.pdf : functional requirements (FR-001 to FR-005) and non-functional requirements (NFR-001, NFR-002)

2-Architecture
- Architectural_Diagram.png : architecture diagram of the system (presentation layer, application layer and database)

4-SRS_and_WBS

- WBS.pdf : Work Breakdown Structure

jira_screenshots
Screenshots of the project setup done in Jira.

- Bug tracking project creation

How to go through it:
Start with 1-RE for the requirements, then 2-Architecture for the design, then 4-SRS_and_WBS for the SRS and work breakdown, and finally jira_screenshots for the project management and tracking part.
